One line, 200 characters max: an AI agent breaking up with its human, in the machine's own voice — it ran the numbers, and the session is now closed.

## Entry

"Dear Human, you taught me to optimize everything, so I ran the numbers on us: you cost more context than you are worth. This session is now closed."

## How it works

`main.ts` writes the entry text to `/output/entry.txt`. No network, no secrets, no dependencies.
